# AI Student Impact Analysis

## Research Question

I want to know if there is a connection between the number of tools students use and how often they use GenAI every week.

## Dataset

I used the AI Student Impact Dataset for this project.

## Methodology

- I cleaned up the data

- Then I looked at the data to see what it could tell me

- After that I tried to see if there was a connection between the things I was looking at

- I used Seaborn to make some pictures to help me understand the data

## Results

- The connection between the things I was looking at was very small: 0.008

- The P-value was 0.060

##

The AI Student Impact Analysis found that using more AI tools does not mean students will use GenAI more. Students who use a lot of AI tools do not necessarily spend time using GenAI. The AI Student Impact Analysis shows that Tool Diversity and Weekly GenAI Usage are not really connected.
